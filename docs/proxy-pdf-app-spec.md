# デュエル・マスターズ プロキシPDF作成アプリ — 仕様メモ

## 目的

ブラウザ上でカード画像を追加し、デュエル・マスターズの実カードサイズで印刷できる A4 PDF を作成するアプリ。切り抜いたプロキシを通常のカードと一緒にスリーブへ入れて使用する。

## 初期スコープ

- 対象はカード表面のみとする。
- 画像の処理はブラウザ内だけで完結させる。
- ログイン、サーバー側の保存、バックエンド、データベースは設けない。

## 画像入力

- 1 つの画像追加エリアで、次の入力方法に対応する。
  - ドラッグ＆ドロップ
  - ファイル選択
  - クリップボードからの画像貼り付け
- 追加した画像は一覧で表示する。

## 枚数（コピー数）

- 追加時の初期枚数は 1 枚とする。
- 各画像の枚数は、プラス／マイナス操作で 0〜4 枚の範囲で変更できる。
- 枚数が 0 になった項目は一覧から削除する。
- 現在の合計枚数を常に表示する。
- 合計枚数（カード面／アイテム）の上限は 81 枚とする。上限に達した場合は、画像の追加および枚数の増加を受け付けない。
- 81 枚の上限は、通常のカードに加えて、両面のサイキック・クリーチャー／超次元カードのカード面も収容できるようにするための容量とする。

## PDF 出力

- A4 縦、片面印刷の PDF とする。
- 1 ページにつき 3 列 × 3 行、最大 9 枚を配置する。
- カードの最終サイズは、幅 63 mm × 高さ 88 mm とする。
- カード間の間隔は 1 mm とする。
- 枠線、裁ち落としマーク、トリム線、レジストレーションマークは付けない。
- 枚数に応じてページを自動的に追加し、最大 9 ページまでとする。
- 生成した全ページを 1 つにまとめてダウンロードできるようにする。
- 81 枚の場合は 9 ページとし、各ページに 9 枚を配置する。

## 画面構成

白を基調とした、1 画面完結のツール指向ページとする。

- 上部：画像追加エリア
- 中央：追加画像の一覧、各画像のコピー数、削除操作
- 下部：合計枚数、印刷設定の概要、PDF 作成ボタン

## 技術構成

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- jsPDF
- すべてブラウザ内で処理する。

jsPDF では、A4 上に実寸で配置するため、座標系をミリメートルに設定し、画像の寸法もミリメートルで扱うこと。shadcn/ui は、ボタン、一覧／カード、ダイアログ、アップロードエリアなどのコンポーネントに使用する。
